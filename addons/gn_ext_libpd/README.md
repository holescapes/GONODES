# gn_ext_libpd — LibPd Pure Data Integration

Pure Data (Pd) audio synthesis integration for GONODES via [libpd](https://github.com/libpd/libpd).

## Operators

| Operator | Description |
|----------|-------------|
| PdSynthCHOP | Run a Pd patch as an audio synthesizer |
| PdFilterCHOP | Process audio through a Pd patch as an effect |
| PdControlCHOP | Send/receive control messages to/from Pd |

## Requirements

- **libpd** native library (compiled from source or pre-built)
- Place the compiled library in `native/bin/` (e.g., `libpd.dll`, `libpd.dylib`, `libpd.so`)

## Building libpd

```bash
git clone https://github.com/libpd/libpd.git native/libpd
cd native/libpd
# Windows (MSVC):
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
# Copy libpd.dll to native/bin/
```

## Pd Patch Format

Place `.pd` files in your project. Reference them by path in the operator's `patch` parameter.

### PdSynthCHOP
- No audio input required
- Outputs stereo audio generated by the Pd patch
- Send frequency/amplitude/note messages via parameters

### PdFilterCHOP
- Audio input processed through Pd patch
- Input audio sent to Pd `[adc~]`, output from `[dac~]`

### PdControlCHOP
- Send float/bang/symbol messages to named receivers in Pd
- Receive values from Pd senders as output channels
