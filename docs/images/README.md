# Image slots

The root README names these slots. Drop a file at the path, then replace the note in `README.md` with the image link.

| Slot | File | What to shoot |
|------|------|----------------|
| `hero` | `docs/images/hero.png` | Wide shot of the editor with a patch on screen. |
| `patch` | `docs/images/patch.png` | A few operators wired together, parameters visible. |
| `player` | `docs/images/player.png` | The standalone player on a display, no editor chrome. |
| `display` | `docs/images/display.png` | The same patch on a projector or an LED wall. |
